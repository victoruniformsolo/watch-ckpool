# Watch Ckpool
## About
Custom developed android app to watch BTC address mining at ckpool.org
* Built with love and assisted by Google Gemini AI
* Dedicated to all ckpool solominers eagerly awaiting any new Bestever and Bestshare

## Features
* Monitors the user selected values
  * Notify/log changes (bestshare,bestever...)
* Separate tracking for Miner/Workers activity
  * Generates activity Timeline

## Compatibility: Minimun Android 13 (SDK 33)
* Testing devices ([Screenshots](https://github.com/victoruniformsolo/watch-ckpool-public/tree/master/assets/screenshots))
  * Adroid 14 (Realme)
  * Adroid 15 (Motorola)

## Installation
Download the [installation APK file](https://github.com/victoruniformsolo/watch-ckpool-public/releases) to android device and run.
* _requires to Enable Unknown Sources as the app is not published on Play_
